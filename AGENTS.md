# Règles visuelles permanentes

- Ne jamais afficher de numérotation décorative ou séquentielle dans l’interface : pas de `01`, `02`, `03`, `04`, ni de `1`, `2`, `3`, `4` utilisés comme étiquettes de cartes, d’étapes, de sections ou de listes.
- Utiliser à la place un titre clair, une coche discrète ou aucun marqueur.
- Les nombres fonctionnels restent permis quand ils sont nécessaires au contenu : numéro de téléphone, mesure, quantité, prix, date ou code technique non décoratif.
- Après chaque modification de l’interface, vérifier toute la page et lancer les tests afin de confirmer qu’aucune numérotation décorative n’a été ajoutée.
